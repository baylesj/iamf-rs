Pure-Rust decoder for IAMF (Immersive Audio Model and Formats / Eclipsa Audio) integrated into Chromium behind media::IamfAudioDecoder, supporting IAMF v1.1 channel/scene streams and IAMF v2.0 object-based rendering.

01player

Select an IAMF-in-MP4 stream to append into a browser MediaSource buffer. The IAMF v2.0 streams use primary_profile = 3 (Base-Advanced object-based audio), which decodes exclusively when iamf-rs is active; stock Chrome (iamf_tools C++) rejects IAMF v2.0 in mp4::IamfSpecificBox.

02probe

Live browser capability and pipeline checks. Note that stock Chrome's MIME parser (crbug.com/438106645) accepts any iamf.000..255.* string in isTypeSupported(), even though its C++ iamf_tools demuxer and decoder only support profiles 000 and 001. 03builds

Pre-built Chromium release binaries with iamf-rs enabled by default. You can toggle between iamf-rs (Rust) and iamf_tools (C++) at any time via chrome://flags/#iamf-rs-audio-decoding or with --disable-features=IamfRsAudioDecoding.
