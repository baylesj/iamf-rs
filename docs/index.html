Run the Chromium Prototype Builds Locally (Linux x64 & macOS arm64)

Both release builds include proprietary_codecs = true, ffmpeg_branding = "Chrome", and both iamf-rs (Rust) and iamf_tools (C++) compiled in so you can toggle between them via feature flag.

Linux x64 Release Build

Download chrome-iamf-linux-x64.zip (182 MB) 
unzip chrome-iamf-linux-x64.zip
cd chrome-iamf-linux-x64
# Launch with pure-Rust iamf-rs decoder (v1.1 + v2.0):
./chrome --enable-features=IamfRsAudioDecoding \
  https://baylesj.github.io/iamf-rs/

# Compare against C++ iamf_tools (v1.1 only):
./chrome --disable-features=IamfRsAudioDecoding \
  https://baylesj.github.io/iamf-rs/

macOS Apple Silicon (arm64) Release Build

Download chrome-iamf-mac-arm64.zip (184 MB) 
unzip chrome-iamf-mac-arm64.zip
xattr -cr Chromium.app
# Launch with pure-Rust iamf-rs decoder (v1.1 + v2.0):
./Chromium.app/Contents/MacOS/Chromium \
  --enable-features=IamfRsAudioDecoding \
  https://baylesj.github.io/iamf-rs/
