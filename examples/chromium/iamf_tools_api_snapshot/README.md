# iamf-tools API header snapshot

These are the public decoder API headers of
[iamf-tools](https://github.com/AOMediaCodec/iamf-tools). They are here only
so CI can compile-check the reference adapter in the parent directory.

- **Source:** copied verbatim from iamf-tools tag v3.0.0
  (5ad3728679495d0037c9be7334338f2859d2a3fa). This version adds
  `TrimmingSettings` and `OutputLayout::kIAMF_Binaural` to the decoder API.
- **License:** BSD 3-Clause Clear License and Alliance for Open Media Patent
  License 1.0. See the iamf-tools repository and this project's `NOTICE`.

In a Chromium checkout, use the in-tree `third_party/iamf_tools` headers
instead of this snapshot.
